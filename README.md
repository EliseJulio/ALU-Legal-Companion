# ALU Legal Companion

A web platform that gives ALU students and staff a verified directory of the Rwandan bodies that solve legal problems, tells them where each kind of matter must go first (with the law, the steps and the deadline), tracks a matter with deadline reminders and offers legal guides and anonymous help-seeking.

Capstone project — BSc Software Engineering, African Leadership University (Rwanda).
Specialisation — Full-Stack Web Development
**Author:** Elise Julio HAKIZIMANA

## Stack
- **Backend:** Node.js 18+ / Express 4 (ESM), REST under `/api`
- **Database:** PostgreSQL 16, raw SQL through `pg`
- **Frontend:** React + Vite + Tailwind
